Mortgage Calculator

Calculate mortgage payments and early payoff savings.

I chose to work on this project because, while using other people's websites to figure out housing costs, I became tired of being swarmed with adds for mortgage loans/realtors/home insurance, and I became nervous that information was being sold companies.

Coded with Python's Flask and Matplotlib modules, containerized with Docker, hosted in Azure Container Apps, with a CI/CD pipeline using GitHub Actions and infrastructure provisioned via Terraform.
